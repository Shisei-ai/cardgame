# ゲームデザイン資料

- カードの一覧は [CARDS.md](CARDS.md)（`node tools/cardlist.js > docs/CARDS.md` で自動生成）
- カード単位の強さの測定結果は [cardpower-result.txt](cardpower-result.txt)

## 1. コンセプト

> 制限時間内に、相手と**同時に**カードを使い合う。相手の動きを**見てから**対応できるかが勝負を分ける。

草案の要件と、それをどう仕組みに落とし込んだかの対応表です。

| 草案の要件 | 実装した仕組み |
|---|---|
| 制限時間内に敵の体力を0にした方が勝ち | 試合3分・体力30。時間切れ時は残り体力で判定（同値は引き分け） |
| 同時にプレイする「フェーズ制」 | 10秒ごとのフェーズ。フェーズ開始時に2枚ドロー。マナは**時間で回復**（毎秒1、最大10）。両者が自由なタイミングでカードを使う |
| 相手のアクションにリアルタイムで対応 | **詠唱時間**と**詠唱スロット1つ**（後述） |
| クリーチャーの攻撃が基本、召喚時に1回 | 召喚時に自動で1回攻撃。以後は【突撃命令】【一騎討ち】などで再攻撃 |
| 召喚・ドロー・リソース・妨害・回復 | 7種類（クリーチャー／召喚術／攻撃／ドロー／リソース／妨害／回復・防御）・**計220種** |
| 40枚デッキ・同名4枚まで | `engine.js` の `CONFIG.deckSize` / `maxCopies`。保存時・対戦開始時に検証 |
| 火力・コンボ・妨害など多様な戦略 | **11のテーマ**と、各テーマの見本・テーマをまたぐ混成デッキの見本（計14プリセット） |

## 2. 中核の仕組み：詠唱

リアルタイムで「同時に出す」だけだと、操作の速さ勝負になりがちです。そこで次の2つのルールで**駆け引き**を生み出しています。

1. **詠唱時間**：カードは使ってから発動まで 0.4〜5秒かかる。その間、何を詠唱しているか相手に公開される。
2. **詠唱スロットは1つ**：詠唱中は次の（詠唱が必要な）カードを使えない。

これにより、
- 重いカード（古竜：4秒）は強いが、**見てから打ち消される**リスクがある
- 軽いカード（疾風の狼：0.6秒）は反応される前に通りやすいが、効果は控えめ
- 【瞬間】カード（打ち消し・詠唱妨害・防壁など）は詠唱不要で、自分の詠唱中にも使える＝**対応手段**
- 打ち消しを温存する相手には、安いカードで打ち消しを「釣る」、【凍てつく鎖】で封印してから本命を通す、などの読み合いが生まれる

という構造になります。【瞬唱】（次のカードの詠唱時間を0にする）は、この構造を逆手に取る「踏み倒し」カードです。

## 3. ルール（v0.2で追加・変更したもの）

カードを100種に増やす過程で、次のルールを追加・変更しました。いずれもシミュレーションで見つかった問題への対策です。

### 守護：1フェーズに1回・反撃なし
**守護は攻撃を受け止めても反撃せず、受け止められるのは1フェーズに1回まで。**

当初の「守護は何度でも受け止め、攻撃してきたクリーチャーに反撃する」ルールでは、守護が「毎フェーズ使える無料の除去」になっていました（1/4の盾兵が2/1の剣士を一方的に倒し続ける）。守護を22枚積んだ城塞デッキが、クリーチャー主体のデッキにほぼ全勝（速攻相手に96%）する状態でした。

今のルールでは、守護は**攻撃を吸収する盾役**です。安いクリーチャーで守護を使わせてから本命を通す、全員で一斉に攻撃して守護の数を上回る、といった**タイミングと数の駆け引き**が生まれます。反撃の有無は `CONFIG.guardRetaliate` で切り替えられます。

### 場が満杯なら、一番古い味方が場を譲る
**場（上限5体）が満杯のときにクリーチャーを召喚すると、一番古い味方が倒れる（遺言も発動）。**

以前は満杯だと召喚できず、墓地デッキが小型クリーチャーで場を埋めたまま、マナ10・手札10枚を抱えて40秒以上何もできずに負ける、という「詰み」が起きていました。今のルールでは常に手が打てます。さらに、【骨の兵隊】などの遺言を自分で誘発できるので、墓地テーマとの相性も良くなりました。

### トークン
カードの効果で生成されるクリーチャー（骸骨兵・子狼・新兵）。**出たときに攻撃せず、倒れても墓地に行かず、場が満杯なら生成されない。** 大量展開が強くなりすぎないための制限です。

### 新しいキーワード・仕組み

| 名前 | 効果 | 主なテーマ |
|---|---|---|
| 連撃 | 召喚時に2回攻撃 | 速攻・血の契約 |
| 貫通 | 守護に受け止められても、余ったダメージは本体へ | 速攻・巨獣（守護への対抗手段） |

### v0.3で追加した仕組み

| 仕組み | 内容 | 設計上の注意 |
|---|---|---|
| 捨てる | 手札→墓地。「2枚引いて1枚捨てる」など | 対象を選ぶUIがないため、**捨てるカードはランダム**。運の要素を逆手に取るのが【狂気】 |
| 狂気 | 手札から**捨てられた時**に発動（コストなしで召喚、1枚引く など） | 相手の【精神破壊】で捨てさせられても発動する。手札破壊への対抗手段にもなる |
| 生贄 | 使うときに味方を指定数だけ破壊する追加コスト | **弱い順（トークン優先）に自動選択**し、誰が生贄になるか手札に表示する。詠唱前に支払うので、**打ち消されると生贄は戻らない**＝リアルタイムの読み合いが生まれる |
| 鈍重 | 召喚時に攻撃しない | 「攻撃は召喚時が基本」というルールの裏返し。能力値が高いので、再攻撃カードや生贄と組み合わせる |
| 前借り・ドロー減少 | 次のフェーズのマナ・ドローを先に使う | フェーズ制だからこそ作れる「時間を前借りする」デメリット |
| 時間条件 | 「残り60秒以下の時のみ」など | 試合時間が決まっているゲームならではの条件。終盤の逆転手段 |

### 条件付きカードとデメリットの設計パターン

ご要望の「条件付きで効果を発動するもの」「メリットとデメリットを合わせ持つもの」は、次のパターンで作りました。既存の効果と意図的に一部重ねつつ、条件やデメリットで差別化しています。

| パターン | 例 | ねらい |
|---|---|---|
| 墓地の枚数が条件 | 墓所の主（10枚以上で 3コスト5/5）、終末の詠唱（15枚以上で12ダメージ） | 墓地を肥やすテーマの「ゴール」 |
| 体力が条件 | 背水の陣（10以下で回復）、逆転の一撃（相手より10以上少ないと7ダメージ） | 負けている側の逆転手段。血の契約と相性が良い |
| 場の状況が条件 | 月夜の狼（味方3体以上で強化）、孤高の剣豪（味方0体で強化）、臆病な傭兵（敵が3体以上だと使えない） | 同じ「条件で強くなる」でも、群れ向き・単騎向きで正反対 |
| 相手の行動が条件 | 静寂の刃（相手が詠唱していない時のみ） | 相手の詠唱を見て「今は撃てない」という判断が生まれる |
| 時間が条件 | 最後の審判（残り60秒以下で全体除去） | 終盤の盤面リセット |
| 自分へのデメリット | 呪われた剣士（体力-3）、暴走ゴーレム（毎フェーズ体力-2）、魔力喰らい（マナを全て失う）、封印の巨像（5秒間カードを使えない） | 能力値はコスト以上。デメリットをどう打ち消すかが腕の見せ所 |
| 相手への利益 | 欲深き商人（相手も2枚引く）、施しの泉（相手も3回復）、二枚舌の商人 | 「相手にも得をさせる」ので使う時機が重要 |
| 両刃 | 等価交換（敵味方の最強を1体ずつ破壊）、自爆兵（全体2ダメージ）、停戦協定（両者封印） | 自分の盤面を整えてから使えば一方的になる |

### v0.4で追加した仕組み

#### 対象を選ぶ
リアルタイムで対象を選ぶのは忙しいので、**選んでいる間は時間を止める**ことにしました（最大5秒、時間切れでキャンセル）。

| 決めたこと | 理由 |
|---|---|
| 対象は**使う時点**で決め、詠唱中は相手にも表示する（🎯） | 「狙われた味方を【送還】で逃がす」「【英雄の加護】で守る」など、相手が対応できるようにするため。詠唱の駆け引きと噛み合う |
| 発動までに対象がいなくなったら**不発** | 対応した側が報われるようにするため |
| 選択中は時間が止まる（最大5秒） | CPUは一瞬で選ぶので、人間だけが時間を取られる不公平をなくす。上限を設けて考え込みすぎを防ぐ |
| 召喚時に対象を選ぶクリーチャーは「対象なしでも出せる」 | 盤面が空のときに手札で腐らないようにするため |

#### 効果の途中で選ぶ
「2枚引いて1枚**選んで**捨てる」のように、効果の途中で選ぶ場合はエンジンが**選択待ち**になり、画面に選択肢を出します。時間切れ（6秒）ならランダムです。CPUは自分の判断で即座に選びます（捨てるなら【狂気】や価値の低いカード、拾うなら価値の高いカード）。

同じ「捨てる」でも、**選べるカード**（選別・研鑽・火葬台・献上）と**ランダムなカード**（灰燼の書・衝動・火葬）を作り分けています。ランダム版は安い・枚数が多いなど、運と引き換えの見返りがあります。

#### 自分の力で攻撃するクリーチャー
v0.2〜v0.3で「大型を出しても再攻撃の手段がないと立っているだけ」という問題が繰り返し起きたため、**クリーチャー自身が攻撃のきっかけを持つ**ようにしました。

| きっかけ | カード | 相性の良い相手 |
|---|---|---|
| 一定時間ごと【自律】 | 番犬（7秒）、戦獣（6秒）、天空騎士（7秒・潜伏） | 強化カード全般（攻撃の回数が多いほど強化が活きる） |
| フェーズ開始時 | 哨兵、雷霆の主（味方全員） | 群れ |
| 自分が呪文を使うたび | 魔法剣士 | 呪文連鎖 |
| 自分が体力を失うたび | 血の猟犬 | 血の契約、自傷のデメリットを持つカード全般 |
| 味方が倒れるたび | 復讐の騎士（味方）、魂刈り（敵味方問わず） | 生贄・墓地・自爆兵 |
| 味方が場に出るたび | 群れの狩人 | トークン生成（群れ）、狂気（捨て札） |
| 自分がカードを捨てるたび | 狂犬 | 捨て札 |
| 強化されるたび | 育つ獣 | 成長、力の付与、殉教者 |
| 攻撃を受け止めるたび | 反撃の盾 | 城塞 |

## 4. テーマをまたぐシナジー

テーマはあくまで目安で、**カード同士は「誘発のきっかけ」を通じてテーマを越えて噛み合う**ように作っています。下の表は「そのきっかけを**起こす**カード」と「そのきっかけで**得をする**カード」の早見表です。左右の列からテーマの違うカードを組み合わせると、新しいデッキの種になります。

| きっかけ | 起こすカード（例） | 得をするカード（例） |
|---|---|---|
| 自分が体力を失う | 血の盟約者・苦痛の契約（代償）、呪われた剣士・暴走ゴーレム（デメリット）、相手の攻撃 | 血の猟犬（攻撃）、狂戦士・捨て身の一撃・逆転の一撃・背水の陣（体力が低いほど強い） |
| 自分が体力を回復する | 吸血、夜の盟主（味方全員に吸血）、癒しの光、生命吸収、施しの泉 | 祝福の巫女（回復のたびにダメージ） |
| 味方が倒れる | 生贄、生贄の祭壇・儀式の短剣、場が満杯での入れ替え、自爆兵、決死隊 | 遺言（骨の兵隊・魂の器・殉教者・原初の卵）、復讐の騎士、魂刈り、血塗れの祭司、腐肉喰らい、墓地の枚数 |
| 味方が場に出る | トークン（狼の母・増援要請）、狂気（炎の魔神）、復活（死霊術師）、送還して出し直し | 群れの狩人（攻撃）、反響の竪琴弾き（召喚時効果を再発動）、月夜の狼 |
| カードを捨てる | 選別・研鑽・灰燼の書・衝動、憑かれた剣士、生命の対価、相手の手札破壊 | 狂気（炎の魔神・荒れ狂う霊）、狂犬（攻撃）、狂気の預言者、墓地の枚数（屍の巨人・終末の詠唱） |
| 強化される | 力の付与・獣使い・成長の歌・殉教者・聖域・森の王 | 育つ獣（攻撃）、自律持ち（強化した攻撃力で何度も殴る） |
| 呪文を使う | 0〜1コストの呪文（火花・マナの雫・突撃指令） | 魔法剣士（攻撃）、見習い魔導士、魔力の奔流、呪文の極意 |
| 召喚時効果 | 狙撃手・断罪の天使・魔導書の番人・炎の小鬼 | 反響の竪琴弾き（もう一度）、送還（手札に戻して使い直す） |
| 墓地が増える | 先見の目・墓所の囁き・墓守りの少年、捨てる効果、倒れたクリーチャー | 墓所の主・終末の詠唱（条件）、屍の巨人（コスト減）、冥府の門、発掘 |

**混成デッキの見本**（プリセットに追加）

| デッキ | 組み合わせ | 動き |
|---|---|---|
| 鋼の歯車 | 自律 × 成長 | 自律で殴り続けるクリーチャーを【力の付与】で強化。強化されるたびに【育つ獣】も攻撃する |
| 血と癒しの円環 | 血の契約 × 回復 | 体力を払うたびに【血の猟犬】、回復するたびに【祝福の巫女】が誘発。【夜の盟主】で全員に吸血を与え、攻撃＝回復＝ダメージの循環を作る |
| 反響する英雄譚 | 召喚時効果 × 送還 | 【反響の竪琴弾き】で召喚時効果を2回発動。【送還】で手札に戻して使い直す |

### 汎用カード（v0.5）

どのデッキにも入るドロー・回復・マナのカードです。どこにでも入る分、似た効果ばかりにならないよう、**効くタイミングや条件**で作り分けています。

| 型 | カード | 差別化のポイント |
|---|---|---|
| すぐ効く | 閃き（瞬間で1枚引く）、回復薬（瞬間で3回復）、魔力の集中（瞬間でマナ+1） | 自分の詠唱中にも使え、相手の攻撃を見てから使える |
| 後から効く | 投資（次のフェーズに3枚引く）、貯蓄（次のフェーズにマナ+3）、再生の祈り（3フェーズ回復し続ける） | 今は損をして、後で取り返す。**フェーズ制ならではの選択**。試合の終盤では効果を受け取る前に試合が終わるので、使いどころが問われる |
| 状況で効く | 補充（手札が5枚になるまで引く）、命の泉（体力差の半分だけ回復）、古地図 | 苦しいときほど強い |
| 体に付く | 魔力の泉（毎フェーズマナ+1）、癒し手（召喚時に回復）、行商人（倒れると1枚引いてマナ+1） | クリーチャーなので場に残る。倒されるリスクがある一方、生贄・墓地とも噛み合う |
| まとめて効く | 天の恵み（2枚引く・4回復・マナ+1）、マナ結晶（マナ+1と1枚引く） | 強カード枠。どのデッキでも採用候補になる |
| このフェーズだけ | 効率化（このフェーズ中、コスト-1） | 手札を一気に使い切りたいフェーズの前に |

**測定結果**：新しい汎用カード20枚中19枚で、平凡なデッキに入れたときの勝率がプラスになった（狙いどおり「どこでも役に立つ」）。回復系が特に高く出たが、これは測定に使う基準デッキが負けがちで体力が減っている場面が多いことによる偏りもあるため、少しだけ弱めている。プリセット9つにも【知識の泉】などの枠と入れ替えて採用した。

## 5. カードデザインの方針

### 強さの配分：弱 2割 / 局所 6割 / 強 2割

各カードは内部に「格付け」（`tier`）を持ちます。プレイヤーには表示しません。

| 格付け | 枚数 | 狙い |
|---|---|---|
| 強 | 44 | どのデッキに入れても強い、またはテーマの柱となる切り札 |
| 局所 | 132 | 単体では平凡だが、合うテーマや状況では主役級に光る |
| 弱 | 44 | 素直だが割高、または効果が控えめ。ただしシナジー次第では化ける（例：【火花】は呪文連鎖の燃料、【石壁】は城塞の頭数） |

**検証方法**：`node tools/cardpower.js` で2つの指標を測定しています。

- **汎用力**：テーマを持たない平凡な基準デッキに4枚入れたら、勝率が何%上がるか
- **テーマ内貢献**：そのカードを使うプリセットから抜いたら、勝率が何%下がるか

**最新の測定結果**（全200種、各指標280試合、誤差は約±4%）：

| 格付け | 汎用力（平均 / 中央値） | テーマ内貢献（平均 / 中央値） |
|---|---|---|
| 強 | +7.4% / +6.1% | +9.6% / +10.4% |
| 局所 | +3.7% / +2.5% | +7.1% / +7.5% |
| 弱 | +2.0% / +1.1% | +6.7% / +5.4% |

- **強 > 局所 > 弱** の順序は、両方の指標で狙いどおり
- 局所カードのうち「テーマ内貢献 > 汎用力」は93枚中60枚。v0.3（78枚中68枚）より下がった。対戦相手が14デッキに増えて汎用力が全体に高めに出ていることと、テーマをまたいで使える汎用的なカードを増やしたことが理由と考えられる
- 汎用力が+15%を超えるのは、ほぼ強カード（突撃命令・鬨の声・魂刈り・打ち消しの印など）。局所カードでは【秘術の模倣】【一騎討ち】のような**再攻撃・再利用系**だけで、このゲームで「攻撃の回数」が特に価値を持つことを示している

### 11のテーマ

テーマ（`arch`）はデッキ構築画面の絞り込みに使われます。1枚が複数のテーマに属することもあり、テーマを混ぜたデッキも組めるようにしています。

| テーマ | 仕組み | 代表的なカード |
|---|---|---|
| 速攻 | 軽いクリーチャーと火力。詠唱が短く打ち消されにくい | 略奪兵（連撃・貫通）、ファイアボルト、火吹き鼠 |
| 群れ | トークンで数を並べ、オーラと全体攻撃 | 号令の旗手（オーラ）、狼の母、群れの長、総攻撃 |
| 妨害 | 打ち消し・封印・手札破壊、「相手が動くたび」の罰 | 打ち消しの印、時間停止、魔力の棘、呪いの刻印 |
| 墓地 | **墓地参照**。山札を墓地へ送り、遺言・復活・墓地の枚数で軽くなる | 墓守りの少年、骨の兵隊、死霊術師、屍の巨人、冥府の門 |
| 呪文連鎖 | 呪文の連打。**詠唱短縮・コスト軽減・コストなし発動** | 見習い魔導士、詠唱の達人、瞬唱、アルカナの賢者、秘術の模倣、魔力の奔流 |
| 血の契約 | **体力をコストに**（マナの踏み倒し）。体力が低いほど強い | 血の盟約者（コスト0・体力3）、苦痛の契約、狂戦士、捨て身の一撃 |
| 城塞 | 守護を並べ、守りの厚さを攻撃に変える | 茨の盾兵（受け止めるとダメージ）、城塞の主、城壁砲 |
| 成長 | フェーズごとに育つクリーチャー、全体強化 | 芽吹く種、大樹の精、森の王、巨大化 |
| 巨獣 | マナ加速、**大型カードのコスト踏み倒し** | 巨獣使い（オーラ）、古代の呼び声（手札から無償召喚）、原初の卵（倒れると山札から召喚）、古竜 |

**分かったこと**
- 「捨てるカードを選べる」ようになると、AIが毎回【狂気】カードを狙って捨てられるため、捨て札が一気に強くなった。**選べる捨て札は、ランダムな捨て札より明確に強い**。そのため、選べるカードはコストや枚数で差をつけている。

### v0.2までの分かったこと
- 最も効いたのは、カードの数値ではなく**ルールの変更**だった（守護の扱い、場が満杯の時の処理）。カードを増やすと、ルールの穴が特定のテーマに集中して表に出る。

## 8. マナの仕様（v0.7）

### 変更の意図
- **より多くのカードを使う快感**：序盤から高いマナで動ける
- **時間の使い方にバリエーション**：今あるマナで使い切るか、少し待って高コストのカードを使うか。マナを自分で操作するカードの価値も上がる

### 仕様
| 項目 | 旧仕様 | 新仕様 |
|---|---|---|
| 最大マナ | 3から始まり、フェーズごとに+1（上限10） | **最初から10で固定**（カード効果でのみ増減。上限15） |
| 試合開始時のマナ | 3 | **5** |
| 回復 | フェーズ開始時に最大まで全回復 | **毎秒1ずつ回復**（最大まで）。フェーズ開始時の回復はない |
| フェーズをまたぐとき | 最大まで回復（v0.6.1で「余りは持ち越さない」に修正） | **そのまま持ち越す** |
| 最大を超える分 | ― | **切り捨て**（カード効果で増やしても最大を超えない） |

「最大を超える分は切り捨て」は依頼にはなかった点で、v0.6.1 の「余剰を溜め込まない」方針を引き継いで決めた。満タンになると回復が止まるので、待ちすぎは損になり、「使い切るか、少し待つか」の判断が生まれる。

### 合わせて変えたこと
- **【魔力共鳴】【大地の脈動】**：最大マナが固定になり「最大マナを増やす」効果が意味を失うため、「**マナの回復速度を永続的に上げる**」効果に変更（毎秒+0.15、+0.4）。試合の早い段階で使うほど得をする
- **AI**：「数秒待てば使える、ずっと価値の高いカード」が手札にあれば、安いカードで散財せずにマナを溜めて待つ（つよい：最大3.5秒、ふつう：2秒、やさしい：待たない）
- **画面**：マナの◆は10個。次に溜まる◆が下から満ちていく。回復速度（+1.0/秒）を表示

### 測定結果（AI同士、全14デッキ）
| | 試合時間 | マナが満タンで溢れている時間 | 手札0〜1枚の時間 | 10秒ごとの使用枚数 |
|---|---|---|---|---|
| 旧仕様 | 55秒 | 5% | 5% | 2.2枚 |
| **新仕様** | 44秒 | 28% | 47% | 2.9枚 |
| （参考）新仕様＋ドロー3枚/フェーズ | 37秒 | 14% | 37% | 3.6枚 |

カードを使う量は約1.3倍に増えた。一方で、**マナの供給にカードの供給（1フェーズ2枚）が追いつかず**、試合時間の約半分は手札が0〜1枚で、4分の1以上の時間はマナが溢れている。対策は 9章（v0.8）を参照。

## 9. 時間ドローと体力50、全カードの見直し（v0.8）

### 決めたこと
マナを時間制にした結果、カードの供給が追いつかなくなった（8章）ため、**ドローも時間制**にし、速くなった試合を**体力**で戻した。

| ドロー | 体力 | 試合時間 | マナが溢れている時間 | 手札0〜1枚の時間 | 10秒ごとの使用枚数 |
|---|---|---|---|---|---|
| フェーズごとに2枚（v0.7） | 30 | 44秒 | 28% | 47% | 2.9枚 |
| 4秒ごとに1枚 | 40 | 46秒 | 20% | 35% | 3.3枚 |
| 3秒ごとに1枚 | 30 | 30秒 | 9% | 17% | 4.1枚 |
| **3秒ごとに1枚（採用）** | **50** | **48秒** | **13%** | **17%** | **3.7枚** |

フェーズは「守護が回復する・フェーズ開始時の効果が発動する」区切りとして残している。

### 新しい経済で分かったこと
- **コストの重みが軽くなった**：マナが毎秒1入るので、コストを1上げても「1秒待つだけ」。調整の道具としては、**詠唱時間**（相手に対応の猶予を与える）と**効果そのもの**の方がよく効く。今回の見直しでも、強すぎるカードはコストと同時に詠唱時間を延ばした。
- **カードの枚数が貴重になった**：安いカードの「安さ」の価値が下がり、**1枚あたりの働き**が重要になった。速攻の軽いクリーチャーが弱くなったので、体力や攻撃力を上げた。
- **マナを構える代償がなくなった**：打ち消しのためにマナを残しておくのがタダ同然になり、妨害が強くなった。そこで【打ち消しの印】に「打ち消した後2秒間、自分もカードを使えない」という**時間の代償**を付けた。
- **相手の行動回数に比例する効果が強くなった**：相手が使うカードの枚数が約1.7倍に増えたため、【魔力の棘】に回数制限を付けた。
- **体力が増えると、守って長期戦にする型が有利**：体力40でも傾向は同じで、主因は体力より経済の変化だった。
- **コスト軽減より、時間の操作**：【巨獣使い】を「大型のコスト-2」から「大型の詠唱時間が半分」に、【魔力共鳴】などを「最大マナ+」から「回復速度+」に作り直した。

### 全カードの見直し
全220種を測り直し、次の観点で点検した。結果は [CARD_REVIEW.md](CARD_REVIEW.md)（1枚ずつの測定値・判定・変更内容）。

1. **新ルールとの整合**：体力を条件にするカード（狂戦士・背水の陣・逆転の一撃）を体力50に換算。フェーズのドローを参照するカード（禁断の知識）、最大マナを増やすカード（魔力共鳴・大地の脈動）を時間制に合わせて作り直した。
2. **格付けとのずれ**：測定で「強すぎ」「強なのに弱い」「局所なのにどこでも光らない」と出たカードを調整。
3. **デッキ単位の偏り**：速攻・捨て札・召喚時効果が弱く、妨害・城塞・自律×成長が強かったため、各テーマの要のカードを調整。

効果や数値を変えたのは計68枚。14デッキの平均勝率は 29〜70%（経済を変える前の v0.5 は 21〜69%）。見直し表の判定は ○ 狙いどおり193枚 ／ △ 強め1枚 ／ △ 弱め26枚（見直し前は 173 ／ 8 ／ 39）。

**残った課題**：「弱め」の多くは誤差の範囲（-3〜-5%）だが、**対象を選ぶ除去**（変化の呪い・等価交換・魅了）は強化しても弱いまま。このゲームではクリーチャーの仕事の多くが「召喚時の攻撃」で終わるため、後から除去しても取り返せるものが少ない、という構造的な理由による。数値ではなく、除去に別の価値（例：除去したら1枚引く、除去した相手の攻撃力分のダメージ）を足す方向で検討したい。

## 10. 見た目の方針（v0.6）

**テーマ**：「時計仕掛けのダークファンタジー」。タイトルの CHRONO（時間）と、詠唱・フェーズという時間が中心のゲーム性に合わせ、深い藍色の地に金の装飾、時計の文字盤・歯車をモチーフにしている。

| 要素 | 作り | 調整する場所 |
|---|---|---|
| 色・フォント | 色は `:root` の変数にまとめている（`--gold`, `--me`, `--op` など）。フォントは見出しが Cinzel（英字）と しっぽり明朝、本文が Zen 角ゴシック。オフラインでは端末の標準フォントになる | `css/style.css` の冒頭 |
| 画面の大きさ | 1280×720 の「舞台」を作り、ウィンドウに合わせて拡大縮小する。itch.io の埋め込みでも全画面でも崩れない | `ui-common.js` の `fitStage` |
| カード | 枠・名前の帯・絵の窓・種類の帯・説明文、左上にコストの宝石、下に攻撃力（ひし形）と体力（円）の宝石。寸法はすべて `em` なので、`--cs` を変えるだけで手札・デッキ構築・拡大表示に同じデザインを使い回せる | `.card` と `--cs` |
| 拡大表示 | `data-cid`（カードID）を持つ要素にマウスを乗せると、大きなカードと、キーワードの意味・テーマの説明を出す。場のクリーチャーは「今の攻撃力・体力」も表示する | `ui-common.js` の `showPreview` |
| 対戦画面 | 手札は扇形。左の台座に詠唱中のカードを置き、周りの枠が詠唱の進み具合を示す。中央の時計がフェーズの進み具合 | `battle.js` の `renderHand` / `renderCast` |

**演出**（エンジンが出すイベントをきっかけに再生する。`battle.js` の `onEvent`）

| きっかけ | 演出 |
|---|---|
| カードを使った | 手札（相手は画面の上）から台座へカードが飛ぶ |
| 攻撃した | クリーチャーが前に突き出し、光の弾が相手（または受け止めた守護）へ飛んで弾ける |
| ダメージ・回復 | 数値が浮かび上がる。プレイヤーは帯が赤く／緑に光り、体力バーに「減った分の残像」が残る |
| 自分が5以上のダメージ | 画面が揺れる |
| クリーチャーが倒れた | 縮みながら色を失って消える |
| 打ち消された | 台座に「打ち消し！」のはんこ |
| フェーズが変わった | 画面中央に PHASE の帯 |
| 自分の体力が30%以下 | 画面の縁が赤く脈打つ |
