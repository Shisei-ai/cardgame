# ARCANA FORGE 設計メモ

## 1. コンセプト

このゲームの目玉は**対戦以外の部分**、つまり「オリジナルカードの生成」。

- 原石を引くと**素質**がランダムに決まり、カードの**容量**（強さの上限）の倍率になる
- コストは自由に決められ、高いほど容量が大きい
- パワー・キーワード効果・テキスト効果が容量を使う。合計が容量に収まればカードの完成

対戦は、作ったカードを試す場であり、カードを作る動機になる場所。

## 2. 対戦のルール（企画書と、確認した細部）

| 項目 | 決めたこと |
|---|---|
| 勝ち方 | 相手の体力（10000）を0にする。山札0枚で引こうとしたら負け（v0.2で体力5000→10000） |
| ターンの流れ | ターン開始（自分のクリーチャーが全てアンタップ）→ 最大マナ+1・マナ全回復 → ドロー → メインステップ → アタックステップ → ターン終了 |
| マナ | 最大マナは0から始まり毎ターン+1、上限20（超高コストのカードを使いこなす戦い方のため） |
| 開始時 | 初期手札5枚。先攻の1ターン目はドローなし |
| 召喚酔い | 召喚したターンは攻撃できない（【速攻】は例外） |
| 攻撃 | 攻撃するとタップ。攻撃先は相手本体か、タップしている相手クリーチャー（【狙撃】はアンタップでも狙える） |
| バトル | パワーが大きい方が勝ち、負けた方は破壊。同じなら両方破壊 |
| 本体への攻撃 | パワーの分だけ体力が減る |
| 守護 | アンタップの守護が、攻撃を代わりに受ける（受けるとタップする）。ブロックという行動はない |
| 迎撃 | 〔迎撃〕の呪文は、相手のクリーチャーが攻撃した時に手札から唱えられる |
| **火種**（v0.2） | 攻撃されるたび、攻撃が終わった後に火種を1つ得る（5つまで）。マナの代わりに使えるほか、1つ払って相手本体への攻撃をアンタップのクリーチャーでブロックできる（2.5章） |
| デッキ | 40枚、同じカードは4枚まで。場は6体まで、手札は10枚まで |

### 2.5 火種：攻撃のリスク（v0.2）

「クリーチャーでのアタックがリスクになる仕掛け（相手が何かしらのリソースを得る）」として入れた。

- 相手のクリーチャーに攻撃されるたび、**攻撃が終わった後に火種を1つ**得る（上限5、ターンをまたいで残る）
- 火種は**マナの代わり**に使える（まずマナから、足りない分を火種で）。迎撃呪文にも使える
- 火種を**1つ払って、相手本体への攻撃をブロック**できる。アンタップの自分のクリーチャーが受け止め（タップする）、攻撃してきたクリーチャーとバトルする。【隠密】はブロックできない

**なぜブロックも付けたか**：最初は「マナの代わりに使える」だけにしたが、試合の長さはほぼ変わらなかった（1人約6.4ターン）。お互いが同じように攻撃するので、お互いが同じように火種を得て、差が出ないためだ。受け取った火種を**守りに使える**ようにして初めて、攻撃のリスクとして働いた。

**なぜ「攻撃が終わった後」に得るか**：攻撃を宣言した瞬間に得ると、その攻撃をすぐブロックできてしまい、実質「誰でもいつでもブロックできる」になる。終わった後に得るので、**1回目の攻撃は通るが、2回目からはブロックされうる**。どのクリーチャーから、何回攻撃するかの読み合いが生まれる。

| 設定（体力10000） | 1人あたりのターン数 | 決着時の最大マナ |
|---|---|---|
| 火種なし | 約6.5 | 約7.5 |
| 火種（マナとしてだけ使える） | 約6.4 | 約7.5 |
| **火種（マナ＋ブロック）、上限5（採用）** | **約10** | **約11** |
| 火種（マナ＋ブロック）、上限3 | 約9.7 | 約10.7 |

### 先攻と後攻の差

v0.1（火種なし）では、補償なしだと先攻の勝率が約69%だったため、後攻に「初期手札+1枚、最初のターンだけマナ+1」を付けていた（約54%）。

v0.2で火種を入れると、補償なしで**先攻の勝率が約49%**になった（先攻が先に攻撃すると、後攻に火種が渡るため）。ルールを単純にするため、後攻の補償はなくした（`secondBonus` / `secondCoin` を0に）。

以下は v0.1 の時の測定（各800戦）。

| 後攻の補償 | 先攻の勝率 |
|---|---|
| なし | 約69% |
| 初期手札+1枚 | 約66% |
| 初期手札+1枚、最初のターンだけマナ+1（採用） | 約54% |
| 初期手札+1枚、最初のターンだけマナ+2 | 約40%（後攻が強すぎる） |
| 初期手札+1枚、後攻の最大マナを1から始める | 約29%（後攻が強すぎる） |

マナ1の差がとても大きいゲームだと分かる。

## 3. カードを作る規則（`js/parts.js`）

### 容量

**容量 ＝（10 ＋ 10 × コスト）× 素質の倍率**（小数切り捨て）

| 素質 | 倍率 | 出やすさ |
|---|---|---|
| 鉄 | ×0.75 | 30% |
| 銅 | ×0.9 | 28% |
| 銀 | ×1.0 | 22% |
| 金 | ×1.15 | 12% |
| 白金 | ×1.3 | 6% |
| 星輝 | ×1.6 | 2% |

基本カードは全て「銀」で作っている。

### 容量の使い方

- **パワー**：パワー40ごとに1。5000を超える分は1.5倍（体力5000を一撃で削れる大型は割高に）
- **キーワード効果**：1つごとに決まった量（守護8、刺客14、速攻10、連撃16、貫通8、隠密10、不屈10、狙撃12、吸収8、加護8）。**デメリット**の【鈍重】（攻撃できない）は12、【自壊】（ターンの終わりに破壊）は18、容量が**戻ってくる**
- **テキスト効果**：3.5章の文法で組み立て、要素ごとの倍率を掛け合わせる

## 3.5 テキスト効果の文法（v0.3）

### 目標

「容量さえクリアできれば、作りたい能力を作れる」。選択式のまま、既存のTCG・DCGで見かける効果を十分に再現できるだけの選択肢を用意する。ただし、壊れた効果は容量と上限で止める。

### 要素

1つのテキスト効果は、次の要素の組み合わせ。選んだ要素から文章が自動で組み上がる。

| 要素 | 選択肢（数） | 例 |
|---|---|---|
| 発動の場面 | 29 | このクリーチャー（召喚・攻撃・攻撃された・受け止めた・バトル・勝利・相手にダメージ・破壊・場を離れた）、ターン（自分／相手の始め・終わり）、場の出来事（味方／相手の召喚、味方／相手の破壊、自分／相手の呪文、相手の攻撃、手札を捨てた、ダメージを受けた、回復した、火種を得た）、【起動】、【常在】、呪文（唱えた時、〔迎撃〕、〔対抗〕） |
| 回数 | 4 | 各ターン1回（×1.0）、各ターン2回まで（×1.5）、何度でも（×2.0）、1試合に1回（×0.5） |
| 条件（2つまで） | 19 | 手札◯枚以下／以上、体力◯以下／以上、体力が相手より少ない、味方◯体以上／以下、相手◯体以上、相手の方が多い、相手がいない、墓地◯枚以上、山札◯枚以下、最大マナ◯以上、火種◯つ以上、このターンに呪文を唱えた、相手の手札◯枚以下、第◯ターン以降、守護がいる、このクリーチャーがタップしている |
| 代償 | 9 | 「〜してもよい。そうしたら」。タップ、手札を捨てる、体力を払う、マナを払う、火種を払う、このクリーチャーを破壊、他の味方を破壊、墓地を除外。起動効果ではコストになる |
| 効果 | 49 | 下の表 |
| 対象 | 誰を6 × 何体4 × 選び方4 × 絞り込み9 | 「パワー3000以下の相手のクリーチャーを2体まで選び」「パワーが最も大きい他の自分のクリーチャー1体に」「攻撃してきたクリーチャーを」など |
| 期間 | 3 | このターン、次の自分のターンの始めまで、ずっと |
| 〜につき | 8 | 味方1体につき、相手1体につき、手札1枚につき、墓地3枚につき、火種1つにつき、このターンの呪文1枚につき…（最大6倍） |

効果（49種）：

| 分類 | 効果 |
|---|---|
| カード・手札 | 引く、引いて1枚捨てる（ルーティング）、自分の手札を捨てる（デメリット）、相手の手札をランダムに／見て選んで捨てさせる、山札からクリーチャー／呪文をサーチ、山札の上を見て1枚を手札に、墓地から回収（クリーチャー／何でも）、自分／相手の山札を墓地へ |
| マナ・火種 | マナを回復、最大マナを増やす、相手の最大マナを減らす、火種を得る、相手の火種をなくす、次のカードのコストを下げる |
| 体力 | 相手にダメージ、ダメージを与えて回復（ドレイン）、お互いにダメージ、回復、自分にダメージ（デメリット） |
| 除去 | 破壊、除外、手札に戻す、山札の一番下へ、パワーを下げる、バトルさせる（格闘） |
| 妨害・封じ | タップ、凍結、能力を消す、コントロール奪取（このターン／ずっと）、呪文封じ・召喚封じ・攻撃封じ・打ち消し（〔対抗〕専用）（この4つと「相手のコスト+1」はメタ効果。下の歯止めを参照） |
| 強化 | パワーを上げる、キーワード効果を与える、アンタップ、もう1回攻撃、破壊されないようにする |
| 召喚 | トークン（パワーとキーワードを選べる）、墓地から蘇生、手札からコストなしで出す、山札の一番上がクリーチャーなら出す、このカードを手札に戻す |
| 常在専用 | 自分のカードのコストを下げる、相手のカードのコストを上げる（パワー・キーワードの付与も常在にできる） |

1つのテキスト効果だけで、組み合わせはおよそ160億通り（規則で弾かれる組み合わせも含む概算）。

### 容量の計算

**容量 ＝ 効果の基本値 × 対象の倍率 × 発動の場面 × 回数 × 条件 × 代償 × 倍化**

- 効果の基本値：例）カードを引く 1枚8、破壊38、除外44、手札に戻す18、パワー+500（このターン）約3・（ずっと）10、相手に1000ダメージ20、最大マナ+1で12、コントロール奪取（ずっと）55
- 対象：2体×1.7、3体×2.3、全て×2.5、ランダム×0.75、最も小さい×0.7、パワー2000以下×0.6、タップしている×0.7、敵味方問わず×0.85、このクリーチャー×0.8
- 期間：次のターンまで×1.25、ずっと×2.5（パワーの増減）
- 倍化：味方1体につき×2.2、手札1枚につき×2.6 など（「平均してこれくらいの数になる」という見込み）

### 暴走を防ぐ決まり（容量とは別の上限）

| 決まり | 理由 |
|---|---|
| **メタ効果**（相手のカードの使用を制限する効果）は容量を多く使い、カードのコストにも下限がある（v0.3.1）：呪文封じ 容量40・コスト6以上／召喚封じ 45・6以上／攻撃封じ 55・7以上／打ち消し 45・5以上／相手のコスト+1（常在） 50・6以上 | 相手が何もできなくなる効果は、遊びの面白さを大きく損なう。容量だけだと、素質の高い原石（星輝×1.6）なら軽いカードにも付けられてしまうので、コストの下限で必ず「重い切り札」にする |
| テキスト効果は3つ、キーワード効果は3つ、条件は1つの効果に2つまで | カードが読める長さに収まるように |
| デメリット（容量が戻る効果やキーワード）で戻るのは、容量の1/4まで | 「デメリットを積んで、強すぎる効果を安く作る」のを防ぐ |
| 「何度でも」は、アンタップ・追加攻撃・タップする起動効果には付けられない | 無限攻撃・無限起動を防ぐ |
| 「〜につき」は最大6倍まで | 盤面次第で天井知らずになるのを防ぐ |
| 効果の連鎖は12段まで、1つの効果は1ターンに10回まで（エンジン） | 誘発が誘発を呼ぶ無限ループを防ぐ |
| **1ターンに使えるカードは12枚まで**（エンジン） | ランダム生成のテストで「マナを回復＋コストを下げる＋墓地から同じカードを回収」の呪文が無限ループを起こしたため。容量では防げない種類の暴走 |
| 「このカードを手札に戻す」は破壊・場を離れた・ターンの終わり・バトルに勝った時だけ、召喚した時に自分を手札に戻すのは不可 | 召喚→戻す→召喚…の繰り返しを防ぐ |
| カードコードを読み込む時も、同じ規則で容量を計算し直す | 書き換えた不正なカードを読み込ませない |

### 確かめ方

- `node tools/check.js`：基本カード57種が規則を満たすか
- `node tools/fuzz.js`：ランダムに作ったオリジナルカードだけで大量に対戦させ、エラー・無限ループがないか、全ての効果と発動の場面が実際に動いたかを確かめる（600戦：エラー0、終わらない試合0。発動しなかったのは、ランダム生成で作らないデメリット効果2つだけ）

### 古いカードの扱い

v0.2までに作ったカード（保存されたもの・カードコード）は、読み込む時に自動で新しい形式に直す。容量の計算が変わったので、容量に収まらなくなったカードは工房の一覧に ⚠ が付く（作り直せば直る。そのままでも対戦には使える）。

## 4. 容量を「強さの物差し」として使う

容量はカードの強さの見積もりそのものなので、CPUもこれを使っている。

- 手札のどのカードを先に使うか：使った容量が大きいほど価値が高いとみなす
- 攻撃するかどうか：相手へのダメージ（パワー40につき1）と、タップして狙われる危険（クリーチャーの容量）を比べる
- CPUのカード作り：原石を引き、容量の5〜8割をパワーに使い、残りでキーワードと効果を試しに足し、最後に余りでパワーを上げる

## 6. 試合の長さ（v0.1で相談 → v0.2で対応）

v0.1では試合が短く（1人約5.7ターン、決着時の最大マナ約6）、最大マナ20の狙いに合っていなかった。
v0.2で**体力を10000に**し、**火種**（2.5章）を入れて、1人約10ターン・決着時の最大マナ約11になった。

体力だけを10000にしても1人約6.5ターンまでしか延びなかった。ダメージは場のクリーチャーが増えるにつれて雪だるま式に増える（巡ごとの与ダメージ：3巡目で約2100、5巡目で約3600）ので、体力を倍にしても試合は倍にならない。守りの手段（火種のブロック）が効いた。

最大マナ20まで届く試合はまだ少ない。マナを伸ばすカードを増やすか、さらに長くするかは、実際に遊んでから決めたい。
