# ゲームデザイン資料

## 1. コンセプト

> 制限時間内に、相手と**同時に**カードを使い合う。相手の動きを**見てから**対応できるかが勝負を分ける。

草案の要件と、それをどう仕組みに落とし込んだかの対応表です。

| 草案の要件 | 実装した仕組み |
|---|---|
| 制限時間内に敵の体力を0にした方が勝ち | 試合3分・体力30。時間切れ時は残り体力で判定（同値は引き分け） |
| 同時にプレイする「フェーズ制」 | 10秒ごとのフェーズ。フェーズ開始時にマナ全回復＋2枚ドロー。フェーズ中は両者が自由なタイミングでカードを使う |
| 相手のアクションにリアルタイムで対応 | **詠唱時間**と**詠唱スロット1つ**（後述） |
| クリーチャーの攻撃が基本、召喚時に1回 | 召喚時に自動で1回攻撃。以後は【突撃命令】【一騎討ち】などで再攻撃 |
| 召喚・ドロー・リソース・妨害・回復 | 6種類（クリーチャー／攻撃／ドロー／リソース／妨害／回復）・計31種 |
| 40枚デッキ・同名4枚まで | `engine.js` の `CONFIG.deckSize` / `maxCopies`。保存時・対戦開始時に検証 |
| 火力・コンボ・妨害など多様な戦略 | 3つのプリセットデッキでそれぞれの戦略を体現し、相性関係を作った |

## 2. 中核の仕組み：詠唱

リアルタイムで「同時に出す」だけだと、操作の速さ勝負になりがちです。そこで次の2つのルールで**駆け引き**を生み出しています。

1. **詠唱時間**：カードは使ってから発動まで 0.4〜4秒かかる。その間、何を詠唱しているか相手に公開される。
2. **詠唱スロットは1つ**：詠唱中は次の（詠唱が必要な）カードを使えない。

これにより、
- 重いカード（古竜：4秒）は強いが、**見てから打ち消される**リスクがある
- 軽いカード（疾風の狼：0.6秒）は反応される前に通りやすいが、効果は控えめ
- 【瞬間】カード（打ち消し・詠唱妨害・防壁）は詠唱不要で、自分の詠唱中にも使える＝**対応手段**
- 打ち消しを温存する相手には、安いカードで打ち消しを「釣る」、【凍てつく鎖】で封印してから本命を通す、などの読み合いが生まれる

という構造になります。

### 「呪いの刻印」について
バランス調整の過程で、妨害デッキには「地道に削る」手段がないことが分かったため追加したカードです。「15秒間、相手がカードを使うたびに1ダメージ」。相手に**動くか、待つか**の判断を強いるので、時間制ならではの駆け引きを増やす狙いもあります。

## 3. 調整用の数値（`js/engine.js` の `CONFIG`）

| 項目 | 値 | 意図 |
|---|---|---|
| startHP | 30 | 速攻で約1分半、じっくりで3分弱で決着する程度 |
| matchTime | 180秒 | 初期手札5＋2枚×17フェーズ＝39枚で、40枚デッキをほぼ使い切る長さ |
| phaseTime | 10秒 | 1フェーズで2〜4枚使える程度。短くすると操作が忙しくなる |
| phaseDraw | 2 | 1枚だと中盤以降に手札が尽き、駆け引きが消えた（下記） |
| startMana / maxManaCap | 3 / 10 | フェーズごとに+1。第8フェーズ（70秒）で上限 |
| fieldLimit | 5 | 場の上限 |
| handLimit | 10 | 超過分のドローは焼失 |

## 4. バランス調整の記録

`node tools/simulate.js` で、つよいAI同士を各組み合わせ100〜300戦させた結果です。

| 段階 | 変更内容 | 速攻 | コンボ | 妨害 |
|---|---|---|---|---|
| 初版 | ドロー1枚/フェーズ、試合5分 | 86.0% | 41.5% | 22.5% |
| 1 | 狼・暗殺者・一騎討ちを弱体化、暗殺命令・火炎嵐を軽く | 84.0% | 47.0% | 19.0% |
| 2 | **ドロー2枚/フェーズ、試合3分**に変更 | 78.5% | 28.0% | 42.5% |
| 3 | コンボ側を強化（魔力共鳴・深淵の洞察・古竜など） | 69.5% | 52.5% | 27.8% |
| 4 | **新カード「呪いの刻印」追加**、妨害デッキ調整 | 62.8% | 47.0% | 40.2% |

（デッキ別勝率はミラー戦を除いた値）

**分かったこと**
- 初版では中盤以降に手札が尽き、マナが余って「何もできない時間」が続いていた。ドロー枚数の変更がもっとも効果の大きい調整だった。
- 現状の相性は **速攻 ＞ コンボ ≒ 妨害**。妨害は速攻に不利（32.7%）、コンボとはほぼ五分。
- **AIの強さで結果が変わる**：「ふつう」同士だと 速攻52.3% / コンボ45.3% / 妨害52.3% とほぼ均衡する。反応が速いほど速攻が有利になる。人間のプレイヤーは「つよい」AIより反応が遅いことが多いので、実際の体感は「ふつう」の数字に近い可能性がある。テストプレイで確かめたいポイント。
- 妨害デッキのミラー戦は約2割が引き分け（互いに何もできない）。決着をつける手段をもう一つ足すかは検討事項。
