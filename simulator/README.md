# シールドバトル・シミュレーター（v0.4）

「デュエル・マスターズ」の基本ルールを再現して、ブラウザ上で CPU と対戦できるツールです。
カードの情報は**画像から読み取って登録**できます（非公式のファンメイドツールです）。

- **カード登録**：カードの画像（1枚でも、何枚も写った画像でも）から、名前・文明・コスト・パワー・種族・能力の文章を読み取る
- **能力の自動解釈**：能力の文章を読んで「対戦で動く効果」に変換する（読めなかった文は赤く表示）
- **デッキ**：40枚（同名4枚まで）を組む。デッキリストの画像や、「4 カード名」形式の文字からも作れる
- **対戦**：CPU と1対1。召喚・呪文・攻撃・ブロック・バトル・シールドブレイク・S・トリガーなどを再現。
  横長の卓（上が相手・下が自分、四隅にマナのカウンター、右下に手札、右に行動ボタン）で、カードの説明は指した時だけ、プレイログはボタンで開いた時だけ表示する
- 登録前でも、見本のオリジナルカード（架空のカード）で組んだ5つのデッキで遊べる

## 使い方

ビルド作業は不要です。`simulator/index.html` をブラウザ（Chrome / Edge / Safari / Firefox の最新版）で開くだけで動きます。

ローカルのサーバーで開く場合：

```bash
cd simulator
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

### 画像の読み取り方法（設定画面で選ぶ）

| 方法 | 精度 | 費用 | 必要なもの |
|---|---|---|---|
| **Claude**（おすすめ） | 高い。小さな日本語・複数枚の画像も読める | 読み取りごとに少額（自分の API キーの利用料） | [Claude Console](https://platform.claude.com/settings/keys) で作った API キー |
| **文字認識（OCR）** | 低め。読み取り後に手で直す前提 | 無料 | なし（初回に認識用データを読み込む） |

- API キーは**このブラウザの中（localStorage）にだけ**保存され、画像と一緒に Anthropic の API にだけ送られます。共用のパソコンでは使い終わったら「消す」を押してください。
- 読み取った内容は、保存する前に必ず確認・修正できます。

### 登録したカードの保存

カードとデッキはブラウザの中（IndexedDB）に保存されます。ブラウザのデータを消すと消えるので、カード画面の「書き出し」でファイルに保存しておくと安心です（「読み込み」で戻せます）。

## 再現しているルール

- デッキ40枚・同名4枚まで。対戦開始時にシールド5枚・手札5枚
- 先攻の最初のターンはドローしない
- ターンの流れ：ターン開始（アンタップ）→ ドロー → マナチャージ（1枚まで）→ メイン → 攻撃 → ターン終了
- コストの支払い：コストと同じ枚数のマナをタップ。その中にカードのすべての文明が必要
- 多色カードはタップしてマナゾーンに置かれる
- 召喚酔い（スピードアタッカー・進化クリーチャーは例外）
- 攻撃先は相手プレイヤーか、相手のタップしているクリーチャー
- ブロッカー、バトル（同じパワーなら両方破壊）、シールドブレイク（W/T/Q/ワールド・ブレイカー）
- S・トリガー（呪文・クリーチャー）、G・ストライク
- ダイレクトアタックでの勝利、山札が0枚になったプレイヤーの敗北、パワー0以下のクリーチャーの破壊
- 進化（進化元の条件・重なったカードの移動）
- キーワード：スピードアタッカー、パワーアタッカー、スレイヤー、マッハファイター、ジャストダイバー、攻撃できない、ブロックされない など
- 誘発：出た時・攻撃する時・破壊された時・ブロックした時・バトルに勝った時・ターンのはじめ／終わり
- 効果：ドロー、破壊、手札に戻す、マナ送り、タップ／アンタップ、パワー増減、マナ加速、シールド追加、手札破壊、墓地・マナ回収、サーチ、リアニメイト、シールド焼却、マナ破壊 など
- 常在効果：自分の他の（文明／種族の）クリーチャーのパワーを上げる、自分のクリーチャーにキーワードを与える
- カードの種類：ツインパクト（クリーチャー側・呪文側のどちらでも使える。S・トリガーやスマッシュ・バーストで呪文側を使う）、
  タマシード（バトルゾーンに置くがクリーチャーではない。シンカライズで進化元になる）
- ハイパー化（メインステップ中に他のクリーチャーをタップしてハイパーモードを解放。次の自分のターンのはじめまで）
- ヨビニオン、ガードマン、アタック・チャンス、スマッシュ・バースト、ジャストダイバー、G・ストライク
- 「次のうちいずれか1つを選ぶ」「次の中から2回選ぶ」（「すべての文明があれば全部」も）
- 山札の上から何枚か見て振り分ける、墓地をシャッフルして山札の下へ、手札を山札の下に置いて引き直す、「〜なら」の条件
- 相手の行動に反応する誘発（相手のクリーチャーが出た時・相手が呪文を唱えた時・マナを置いた時・カードを使った時・攻撃する時）、
  「ターンの残りをとばす」（とばされたターンでは「ターンの終わりに」の能力も誘発しない）
- 手札から呪文をタダで唱える、唱えた呪文を墓地からもう一度唱える、相手のターンの終わりに手札からタダで召喚する

- 超次元ゾーン（8枚まで）：サイキック・クリーチャー、ドラグハート（ウエポンは出したクリーチャーに装備、フォートレス）。
  バトルゾーン以外へ行く時は超次元ゾーンに戻る。「コストの合計がN以下になるように好きな数」にも対応
- GRゾーン（0枚か12枚・同名2枚まで）：GR召喚（召喚扱い）。離れるとGRゾーンの一番下へ
- コスト：「〜の召喚コストを1少なくする」（1より少なくはならない）、「相手の呪文を唱えるコストを1多くする」、シンパシー、G・ゼロ
- 置換効果：「破壊される時、墓地に置くかわりに〜」、セイバー、エスケープ、バトルゾーンを離れない
- 革命チェンジ、侵略、ニンジャ・ストライク（ターンの終わりに山札の下へ）、革命0トリガー、マナ武装（「マナに〜のカードがN枚以上あれば」）、離れた時
- 同時に発動した能力は、持ち主が解決の順番を選ぶ（ターンのプレイヤーの能力が先）
- NEO進化（重ねれば召喚酔いしない）、超魂レイド（山札の上3枚から進化元を下に置く）、超魂X（下にあるカードの能力を上のクリーチャーが得る）
- ダブル・シンパシー（エレメント1つにつき2少なく）、「〜あれば、5支払って召喚してもよい」、各ターンに一度のコスト軽減、マナゾーンからの召喚
- 相手への禁止：「相手は（光ではない）呪文を唱えられない」「次の相手のターンの終わりまで呪文を唱えられない」「各ターン合計N回まで」
- パワード・ブレイカー（パワー6000ごとに1枚多く）、チャージャー、「離れるかわりにとどまる」、「クリーチャーが出た時」、シールド化、
  山札の上を表向きにして条件に合うカードをすべて手札に、「このクリーチャーに含まれるカード1枚につき」、同名は2つ以上出せない

### まだ対応していないもの（今後の課題）

サイキック・クリーチャーの覚醒・解除、ドラグハートの龍解、メテオバーンなど「下のカードを使う」能力、
その他の個別の裁定。
対応していない文はカード編集画面に赤く表示されます（意味を変えない範囲で、対応している言い回しに書き換えると動きます）。

### カードの文章の書き方（画像から読み取った後に直す時の目安）

- 能力は1行に1つ。選択肢は「▶」で始まる行に分ける
- ハイパー化を持つカードは「■ハイパーモード パワー11000」の行を入れ、その下にハイパーモード中の能力を書く
- ツインパクトはカード編集画面の「ツインパクト」にチェックを入れ、呪文側の名前・コスト・文章を入れる

## ファイル構成

```
index.html            画面（メニュー・カード・デッキ・対戦の準備・対戦・設定・遊び方）
css/sim.css           見た目
js/data.js            文明・カードの種類・ルールの数値
js/textparser.js      ★能力の文章 → 効果データ（決まった言い回しを正規表現で読む）
js/engine.js          ★ルール処理（ゾーン・ターン・支払い・攻撃・バトル・ブレイク・S・トリガー・勝敗）
js/ai.js              CPU の考え方
js/sample-cards.js    見本のオリジナルカードとデッキ
js/storage.js         カード・デッキ・設定の保存
js/reader.js          画像からの読み取り（Claude API / OCR）・デッキリストの照合
js/ui.js              画面共通の部品（カードの描画・ダイアログなど）
js/library-ui.js      カード一覧・登録・編集
js/deck-ui.js         デッキの作成・編集・読み込み
js/battle-ui.js       対戦画面
js/main.js            起動・対戦の準備・設定
tools/test.js         ルールのテストと、CPU同士の大量対戦
```

## 確認用のコマンド

```bash
node simulator/tools/test.js            # 個別のルールのテスト＋CPU同士200戦
node simulator/tools/test.js --games 500
```

## 注意

- 非公式のファンメイドツールです。公式の名称・ロゴ・カード画像は同梱していません（見本カードはすべて架空です）。
- 登録したカードの画像や文章は、個人で遊ぶ範囲で使ってください。
